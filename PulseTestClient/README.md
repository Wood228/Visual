# PulseTestClient — Minecraft 1.21.4

Fabric client-side test harness focused on local HUD, module toggles, configuration, and explicit test-session telemetry.

## Build

Use Java 21 and run `./gradlew build`.

## Controls

- Right Shift — open GUI
- Insert — toggle test mode
- Home — start test session
- End — stop test session
- Right Ctrl — emergency stop
